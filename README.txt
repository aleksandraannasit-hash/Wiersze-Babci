WIERSZE BABCI TERESY — GOTOWA STRONA INTERNETOWA

JAK OPUBLIKOWAĆ ZA DARMO NA GITHUB PAGES:
1. Załóż bezpłatne konto na https://github.com (jeśli jeszcze go nie masz).
2. Kliknij + → New repository. Nazwij repozytorium np. wiersze-babci-teresy.
3. Wybierz Public i kliknij Create repository.
4. Kliknij Add file → Upload files. Przeciągnij wszystkie pliki z ROZPAKOWANEGO folderu strona_babci_teresy (index.html, style.css, app.js, data.js, poems.json, katalog assets i README.txt). Nie wgrywaj samego ZIP-a.
5. Kliknij Commit changes.
6. Wejdź w Settings → Pages → Build and deployment. W Source wybierz Deploy from a branch, w Branch: main, folder: / (root). Kliknij Save.
7. Po kilku minutach strona będzie pod adresem: https://TWOJ-LOGIN.github.io/wiersze-babci-teresy/

ZMIANY:
- Zawartość wierszy: plik data.js (lub poems.json, ale strona korzysta z data.js).
- Tekst powitalny i notka Oli: index.html.
- Kolory i wygląd: style.css.
- Ilustracje: katalog assets.

WAŻNE:
- Repozytorium Public oznacza, że treści będą publicznie dostępne.
- Upewnij się, że Babcia wyraża zgodę na publiczne udostępnienie wierszy.
- Strona działa bez opłat i bez własnej domeny.
- Do wyświetlania czcionek ozdobnych korzysta z Google Fonts, ale bez internetu użyje standardowych czcionek.
- W oryginalnym zbiorze nie ma wiersza numer 64 — numeracja zachowana.
